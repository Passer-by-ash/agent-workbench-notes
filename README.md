# agent-workbench-notes

> 一个人 + 一堆 AI 会话，从零开始搭一套「能自检的工作台」的过程记录。
> **按时间写的，不是按成果写的。** 每一段记的是当时在解决什么问题、能选什么、为什么选这个、错在哪。

## 为什么按时间写

纯成果会被下一个成果覆盖；**「为什么会有这个成果」不会**。

所以这里不放「最佳实践」，放的是**当时的样子**：那时候还不知道后面会怎么走，判断是带着犹豫和返工的。每节的末尾给一条「回看点」——指回当天的日志或原话，方便核，也方便后来的人（包括我自己）看见判断是怎么变的。

## 怎么读

每个阶段一篇，篇内每节固定五段：

```
遇到什么 → 当时能选什么 → 选了哪个、为什么 → 错在哪 → 留下什么判据
```

- 想看**判断方式**：读「选了哪个、为什么」和「留下什么判据」两段；
- 想看**代价**：读「错在哪」；
- 想核原文：看每节末尾的回看点（日期＋日志小节名）。

## 这里没有什么

- **没有个人内容**：不写交易记录与个人财务、不写家庭与个人经历、不放他人作品正文。
- **没有「后来的我」的结论**：不把后面的认识塞回当时的叙述里——那样就看不见真实的判断过程了。
- **不是库**：不承诺接口稳定、不接需求。这是笔记。
