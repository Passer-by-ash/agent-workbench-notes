# 原话与判断 · 段⑧

> 按当时顺序收：原话 → 当时怎么判 → 落到哪件 → 现在怎么看。**只收与判据有关的话，不收私人内容。**

## 1. 「直接回查当时的历史，然后在本机定位原始文件」

- **当时怎么判**：知识库不是源头，源在本地；先从库条目反查历史会话，再回本机定位原件。
- **落到哪**：方法 §一「权威源是哪一个」——本地原件是权威，库只当文本层与覆盖校验。
- **现在怎么看**：对的。后来 518 篇能逐篇对上原件，靠的就是这条。

## 2. 「单纯的用时间做划分拆不开对应的内容」

- **当时怎么判**：同一时段两份工，时间切不开；改成按事分——这笔钱是谁的、这张票开给谁。
- **落到哪**：分段判据与识别词表；判定顺序写死：专名 → 人名 → 业务词 → 日期窗兜底。
- **现在怎么看**：对的，但有一个代价——121 篇无字手写只能按日期先归，件里必须标明「这是降级」，不能当已判对。

## 3. 「有图片原件的，通通不用 OCR 后的文本」

- **当时怎么判**：OCR 错误太多，手写件只留标题/日期/原件/原图。
- **落到哪**：手写件规则；全库清 101 处 OCR 摘录。
- **现在怎么看**：对的。OCR 只能定位，不能当正文。

## 4. 「剩下的所有待认领，都先归到对应的工作时期」

- **当时怎么判**：先落位再细分；按日期窗归，不硬判。
- **落到哪**：121 篇按日期先归；自查脚本对这批标「零信号，按位置不判」。
- **现在怎么看**：可以先归，但必须留「降级」标记——0 错段只覆盖有文字信号的那一半。

## 5. 「阶段动作做完后，就应该完整进资产整理的总结和经验，按块划分」

- **当时怎么判**：不要每个阶段各留一份总结/经验，会不断累加；一份总结、一份经验，按块分节。
- **落到哪**：两份总结并一份、两份经验并一份；专项说明进总览与方法的「使用说明」。
- **现在怎么看**：对的。文档按「种类」分、不按「项目」分（外部检索也指向这条）。

## 6. 「专项这个文件夹是用来干什么的？」

- **当时怎么判**：建了个「专项」夹，把结项件、在役说明、真实边界混装——答不上来它的职责。
- **落到哪**：撤掉，改三条路：过程件进归档、说明件进总览/方法、常驻件留前台。
- **现在怎么看**：新建目录前先能一句话说清「装什么、不装什么」，说不清就别建。

## 7. 「抽一张结项清单」

- **当时怎么判**：把两批的收尾动作抽成一张七步卡，每步带判据与工具。
- **落到哪**：`30-原件/10-卡-结项清单`；方法 §七 只留「为什么」。
- **现在怎么看**：卡是这一班最值钱的一件——下一摊照着走就够。
