## 六、外部对照

查了四个现成的公众号归档工具（MagicMD / wechat-notebank / wechat-article-exporter / obsidian-wechat-sync）。

**结论：归档动作本身别人都做过，没有一处是我们首创。** 真正有差别的三处：三层结构（发布稿/手稿/回看）、去重用解析后 `ct` + 标题、时间字段带出处。

该学没学的：**转换报告**。这一轮补上了（`07-提取报告.cjs`）。
