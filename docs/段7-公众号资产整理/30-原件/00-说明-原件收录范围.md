# 原件收录范围 · 段⑦

> 这一页解释：**为什么这一段只放了方法件和脚本，没放文章本身。**

## 收什么

**「本来就是给外部看的件」**才作为原件收录——写的时候就没打算只给自己看的东西：

| 件 | 为什么收 |
|---|---|
| `10-方法-资产整理.md` | 方法本身就是要复用的，换个库照样成立 |
| `11-经验-判据与弯路.md` | 判据与弯路，同上 |
| `工具/01~08.cjs` | 八个自检脚本，脱敏后可直接跑 |

## 不收什么，为什么

**不收：716 篇文章正文、1,216 张图、216 条回顾转写、40 篇原始稿。**

四条理由：

1. **是别人的阅读内容，不是我的方法**。文章正文是公开出版物，回看视频转写里还有口述的个人内容。**这一段记的是「怎么整理」，不是「整理出来的东西」。**
2. **可识别**。公众号名、文章链接、`__biz` 参数、B 站视频号，全是定位到具体账号的。要放上去就得逐篇换占位，换完已不是原件。
3. **体量**。716 篇 + 1,216 图，光正文就上百万字。放上来读者也没法核。
4. **收的是「可核」不是「可看」**。想知道整理成什么样，看 `10-件账.md` 的数字表——每一类多少篇、每一年多少篇、断链几处，都能对上。

## 那些东西在哪

在本机的工作台里，不在这个仓。这一段只留**做法**。

## 脱敏做了什么

上传前跑 `工具/08-脱敏门.cjs`，规则逐条：

| 类 | 处理 |
|---|---|
| 本机盘符路径 | 全部换成 `<本机路径>` / `<工作台>` |
| 公众号名 | 换成 `<公众号>` |
| 微信文章链接与 `__biz` 参数 | 换成 `<微信原文链接>` / `<已移除>` |
| B 站视频号 `BV…` | 换成 `<B站视频号>` |
| 平台用户名 | 换成 `<作者>` |
| 手机号／身份证／邮箱 | 硬拦 |

**退出码**：0=GO｜3=GO-CONDITIONAL（只有提示项）｜1=NO-GO（有硬拦）。

本段上传前的结果：**硬拦 0 处**，提示 3 处（脚本里出现 `Windows` / `Administrator` 两个词，是安全规则本身的词表，非个人信息）。
